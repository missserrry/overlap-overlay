# Свой оверлей для iRacing

Личный локальный оверлей: сервер телеметрии и оверлеи **Relative** и **Standings** в стиле RaceLab.
Код и вёрстка свои; размеры, цвета и шрифты взяты из разбора в [reverse/RACELAB_REVERSE.md](reverse/RACELAB_REVERSE.md).

## Запуск

```bash
npm start
```

Откроется панель управления, оверлеи появятся поверх всех окон, в трее — золотой квадратик.

- **Ctrl+Shift+L** — открепить или закрепить оверлеи. Открепленное окно двигается за любое место и растягивается за правый край, низ и правый нижний угол (как в Laki Overlay). При этом оно прилипает к краям и центру экрана и к другим оверлеям, подхватывает ширину и высоту соседа и показывает цветные направляющие. **Shift** — двигать без прилипания. Закреплённые окна пропускают клики в игру.

### Размер оверлея = масштаб

Оверлей заполняет своё окно, как картинка:
- **шире** — всё крупнее, **уже** — мельче;
- **выше** — больше строк (Relative: больше машин вокруг вас; Standings: больше мест в вашем классе и других классах), **ниже** — меньше;
- если сжать по ширине до предела читаемости (≈10 px шрифта), начинают прятаться менее важные колонки:
  Relative — прирост iRating → лицензия → iRating → короткий подвал; Standings — прирост iRating → лучший круг → iRating.
  Отрыв и имя остаются всегда.

Для OBS размер задаётся размером browser source. Для отладки: `/common/fit-test.html?o=standings&s=440x560,300x560`.
- **Ctrl+Shift+H** — скрыть или показать все оверлеи.
- **Ctrl+Shift+J** или клик по трею — открыть панель управления.

### Раскладки (как в Edge Overlays)

- **Раскладка** — набор оверлеев с позициями и настройками. Можно добавлять несколько экземпляров одного оверлея.
- **Когда включать**: все машины, выбранные машины или категория (sports car, formula, oval, dirt) плюс типы сессий.
  При «Автовыборе» включается самая точная подходящая раскладка: машина +100, категория +50, «все машины» +3;
  выбранный тип сессии +10, «все сессии» +1. Если ничего не подошло, включается раскладка, отмеченная как основная.
- **Варианты внутри раскладки**: свой набор для практики, квалификации, гонки и споттинга (когда вы не за рулём).
  Вариант создаётся копией основного набора.
- **У каждого оверлея**: масштаб, прозрачность фона, видимость (на трассе / в боксах / когда iRacing закрыт), кнопка «OBS» с адресом для браузера.
- Ручной выбор раскладки («Включить сейчас» или меню трея) действует до смены машины или сессии.

Всё сохраняется в `%APPDATA%\svoy-overlay\config.json`.

**Важно:** iRacing должен работать в режиме «Windowed» или «Fullscreen windowed» (borderless).
В эксклюзивном полноэкранном режиме Windows не показывает окна поверх игры.

### Ливреи Trading Paints

Панель → **Ливреи**. Работает по схеме Better TP из Kapps (разбор — [reverse/BETTERTP.md](reverse/BETTERTP.md)).
Когда в сессии iRacing меняется список пилотов, приложение спрашивает `fetch.tradingpaints.gg`, какие у них ливреи,
и качает их в `Документы\iRacing\paint`: машина, спекулярная карта `.mip`, декали, шлем и комбинезон.
Сразу после каждого файла iRacing получает команду перерисовать машину. Уже скачанное с тем же размером не качается повторно.
Ливреи, не встречавшиеся N дней, удаляются (только скачанные этим приложением).

- По умолчанию **выключено** — включите переключатель «Загружать».
- Не запускайте вместе с Kapps Better TP или официальным Trading Paints Downloader: панель предупредит, если они запущены.
- Учёт скачанного хранится в `%APPDATA%\svoy-overlay\liveries.json`.

## Без Electron (браузер, OBS)

```bash
npm run server
```

- Relative — http://127.0.0.1:8900/relative/
- Standings — http://127.0.0.1:8900/standings/

Параметры адреса: `?scale=1.3` — масштаб, `?preview` — тёмный фон для просмотра.
`npm run demo` — всегда демо-данные.

## Как устроено

```
iRacing shared memory ──► src/telemetry/irsdk.js   (koffi + kernel32, без компиляции)
demo                  ──► src/telemetry/demo.js     (имитация мультиклассовой гонки)
                              │
                     src/model/race.js              позиции в классе, отрывы, SOF, оценка iRating
                     src/model/relative.js          машины рядом на трассе
                     src/model/standings.js         таблица по классам
                              │
                     src/server/server.js           HTTP + WebSocket /ws/relative, /ws/standings (15 Гц)
                              │
overlays/relative, overlays/standings               страницы оверлеев (чистый JS + CSS в em)
overlays/panel                                      панель управления раскладками
src/main/layouts.js                                 модель раскладок, счёт совпадения, варианты
src/main/state.js                                   активная раскладка, видимость, действия панели
src/main/main.js                                    Electron: окна по экземплярам оверлеев, панель, трей
```

## Колонки таблиц и марки машин

В настройках каждого оверлея (Relative, Standings) есть блок «Колонки»: переключатели и порядок перетаскиванием.
Когда окно сужается, колонки уходят сами — от менее важных к более важным (приоритеты в `overlays/common/columns.js`).
Адрес для OBS содержит выбранные колонки: `/relative/?cols=pos,name,ir,gap`.

Марка определяется по пути машины iRacing (`src/model/brands.js`); если логотипа нет, ячейка остаётся пустой.

Логотипы марок (`overlays/common/brands/`) — чистые знаки без фона: большинство взято из набора car-logos-dataset
(github.com/filippofilip95/car-logos-dataset), обрезаны до знака; McLaren Speedmark, Dallara и Skip Barber — с Wikimedia Commons.
Все они — товарные знаки своих владельцев; в проекте используются только для личного некоммерческого отображения.


## Оверлеи

| Оверлей | Что показывает |
|---|---|
| Relative | машины рядом на трассе и отрыв до них |
| Standings | таблица по классам; лидер каждого класса виден всегда |
| Weather | температура трассы, состояние трассы, осадки, ветер с компасом, который вращается вместе с машиной |
| DigiFlag | светодиодная панель флагов (25×25 точек) с миганием, вид «квадрат» или «две полосы» |
| Radar | кто рядом по бортам и близко спереди и сзади; цвет и размер растут с сближением |

У Relative и Standings настраиваются колонки, шапка и подвал (около 30 пунктов, порядок перетаскиванием), масштаб отдельно от размера окна,
а у Standings ещё и положение разделителя между левой и правой частью. DigiFlag и Radar всегда квадратные.
Все настройки попадают и в адрес для OBS.

## Сборка и запуск

```bash
npm install
npm start          # приложение с панелью (Ctrl+Shift+J — панель, Ctrl+Shift+L — закрепить/редактировать, Ctrl+Shift+H — скрыть все)
npm run dist       # portable exe в dist/
```

Без запущенного iRacing включается демо-режим. Приложение только читает память iRacing и ничего не отправляет в сеть,
кроме необязательной загрузки ливрей Trading Paints.
